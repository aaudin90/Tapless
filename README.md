# TapLess

Голосовой ввод для macOS. Нажимаете горячую клавишу и говорите. Речь локально распознаёт Whisper (WhisperKit на Neural Engine). Затем текст **параллельно** уходит в несколько вариантов оформления: по умолчанию это локальная модель Gemma в [Ollama](https://ollama.com) с вашим промптом и словарём. Вместо неё можно взять Claude Code (`claude -p`) или любую другую CLI. Во всплывающем окне выбираете цифру: **1** — текст как распознан, **2–9** — варианты. Выбранный текст вставляется в окно, которое было в фокусе.

```
⌥Э → говорите → ⌥Э
   ┌───────────────────────────────────────────────┐
   │ ● Выберите вариант                          × │
   │ 1  КАК РАСПОЗНАНО   ну вот короче надо ...    │
   │ 2  КАК СКАЗАЛ       Надо переписать ...  1.4с │
   │ 3  ДЕЛОВОЕ СООБЩ…   ⏳ думаю…                  │
   │ 1–3 — вставить · ⇧+цифра — только копировать  │
   └───────────────────────────────────────────────┘
```

## Требования

- Mac на Apple Silicon (M1 и новее) с macOS 14 или новее.
- Xcode 16 или новее. Достаточно Command Line Tools, если `swift --version` показывает Swift 6.x.
- [Ollama для macOS](https://ollama.com/download/mac). Модель `gemma4:e4b-it-q4_K_M` TapLess скачает сам: около 6,6 ГБ на диске.
- Claude Code — только если выберете harness `claude`: команда `claude` должна работать в Терминале.
- Около 1,6 ГБ на диске под модель `large-v3-turbo`.

## Сборка и установка

```bash
cd Tapless                     # корень репозитория
./build_app.sh --install      # соберёт, положит в ~/Applications и запустит
```

Первая сборка подтягивает зависимости и идёт несколько минут.

При первом запуске:

1. **Микрофон.** macOS спросит разрешение, нажмите «Разрешить».
2. **Универсальный доступ.** Без него TapLess не может нажать ⌘V за вас. Откройте Системные настройки → Конфиденциальность и безопасность → Универсальный доступ и включите TapLess. Пока разрешения нет, выбранный текст просто копируется в буфер обмена.
3. **Модель Whisper.** Скачивается в фоне. Прогресс показан в меню иконки в меню-баре: стрелка вниз значит загрузка, волна значит модель готова. Потом CoreML один раз оптимизирует модель под ваш чип, на `large-v3-turbo` это может занять несколько минут. Следующие запуски проходят за секунды.
4. **Ollama.** TapLess проверяет сервер Ollama. Если приложение Ollama установлено, но не запущено, TapLess запускает его. Если модели нет, скачивает её (~6,6 ГБ), прогресс — в меню: «Ollama: скачиваю …: 42%». Если Ollama не установлена, в меню будет «⚠︎ Установить Ollama…»: установите её и нажмите «Проверить Ollama снова». Пока модель не готова, вставляйте сырой текст клавишей `1`.
5. **Настройки.** Создаётся файл `~/.config/tapless.toml` с закомментированными значениями по умолчанию. Пока в нём ничего не раскомментировано, он ничего не меняет.

> **Важно про подпись.** macOS хранит разрешения на микрофон и Универсальный доступ под подписью приложения. Если сертификата нет, `build_app.sh` подписывает ad-hoc, и после **каждой пересборки** разрешения сбрасываются: в списке Универсального доступа удалите старую запись TapLess кнопкой «−» и добавьте снова. Чтобы этого не было, один раз создайте свой сертификат: «Связка ключей» → меню «Ассистент сертификации» → «Создать сертификат…». Имя `TapLess Dev`, тип «Подпись кода». Дальше `build_app.sh` подписывает им сам. Другое имя сертификата — через `SIGN_IDENTITY="Имя" ./build_app.sh --install`.

### Раздать знакомым

```bash
./build_app.sh --zip           # build/TapLess.zip, подписан сертификатом TapLess Dev
```

Получатель распаковывает архив и переносит `TapLess.app` в `~/Applications` или `/Applications`. Сертификат самоподписанный, поэтому Gatekeeper при первом запуске покажет «Не удаётся проверить разработчика». Есть два способа открыть:

- Системные настройки → Конфиденциальность и безопасность → внизу «Всё равно открыть»;
- или в Терминале: `xattr -dr com.apple.quarantine ~/Applications/TapLess.app`.

То же нужно после каждого скачанного обновления. Разрешения на микрофон и Универсальный доступ при обновлении сохраняются, если сборка подписана тем же сертификатом. Поэтому все сборки для раздачи подписывайте одним сертификатом и храните его копию с закрытым ключом (`.p12`). Если ключ потерян, новый сертификат один раз сбросит разрешения у всех.

## Как пользоваться

| Действие | Клавиши |
|---|---|
| Начать / закончить запись | `⌥Э` (в английской раскладке `⌥'`; меняется в конфиге) |
| Вставить сырой текст без ИИ («Как распознано») | `1` (если `ui.show_raw = true`) |
| Вставить вариант | `2`…`9` или клик по строке (`1`…`9`, если `ui.show_raw = false`) |
| Только скопировать, не вставлять | `⇧` + цифра |
| Отмена / закрыть окно | `Esc` |
| Открыть окно последнего результата снова | `⌥Ж` (в английской раскладке `⌥;`; ключ `general.show_last_hotkey`) или меню → «Показать последний результат». Повторное нажатие закрывает окно |

- Цифру можно нажать заранее, пока вариант ещё «думает». Он вставится сразу, как только будет готов.
- Если окно закрылось (например, фокус ушёл в другое приложение), нажмите `⌥Ж`: окно с последними вариантами откроется снова, а цифра вставит текст в приложение, которое сейчас в фокусе. Пока идёт запись или распознавание, клавиша не работает. `⌥;` в английской раскладке обычно печатает «…»: пока TapLess запущен, это сочетание занято им. Другая клавиша или `show_last_hotkey = ""` — в конфиге.
- Если во время записи сменить микрофон (например, подключить AirPods), запись продолжится на новом устройстве.
- Режим `mode = "hold"` работает как рация: держите клавишу и говорите, отпустили — запись остановилась.
- Пока окно с вариантами открыто, цифры и Esc перехватываются глобально. Окно само закроется, если вы переключитесь в другое приложение.
- Вставка идёт через буфер обмена и ⌘V. Прежнее содержимое буфера возвращается, а менеджерам буфера (Maccy, Raycast, Paste) передаётся пометка «не сохранять».

## Конфиг

Встроенные значения по умолчанию с комментариями лежат в [`config.default.toml`](config.default.toml). Свои значения пишите в `~/.config/tapless.toml` (путь можно поменять переменной окружения `TAPLESS_CONFIG`):

- **Файл важнее дефолтов.** Пишите только то, что меняете, остальное берётся из значений по умолчанию. Ключ раскомментируйте вместе с заголовком его секции (`[general]`, `[llm]` …).
- **Таблицы сливаются по ключам**, в том числе `[variants.<номер>]`, `[llm.env]`, `[harness.<имя>]` и `[dictionary.replace]`. Например, в `[variants.2]` достаточно указать новый `prompt`, а `[variants.3]` добавит третий вариант. **Массивы заменяются целиком:** если задать `terms`, термины по умолчанию не используются.
- **Изменения применяются после перезапуска:** меню TapLess → «Перезапустить (применить конфиг)». Конфиг читается один раз при запуске.
- **Ошибки.** Если файл не разбирается, TapLess покажет ошибку и будет работать на значениях по умолчанию. Шестнадцатеричные, восьмеричные и двоичные числа, `nan` и `inf` не поддерживаются: пишите обычные десятичные числа. Неизвестные ключи (опечатки), неизвестные значения `mode`, `position` и `log.level`, ссылки на несуществующий harness или схему, вариантов больше, чем свободных клавиш, не ломают запуск: TapLess покажет предупреждение и запишет его в лог.
- Приложение файл не перезаписывает: оно только создаёт шаблон, если файла нет. Меню → «Открыть конфиг…».

Пример — своя клавиша и модель Sonnet для всех вариантов:

```toml
[general]
hotkey = "ctrl+shift+d"

[llm]
model = "sonnet"
```

Главное из настроек:

### LLM: harness

Варианты оформляет **harness**: внешняя CLI-программа или локальный сервер Ollama (см. «LLM: Ollama»). По умолчанию это Ollama (`harness = "ollama"`). Пресет `claude` запускает Claude Code (`claude -p`), но подходит любая программа: OpenCode, `llm`, свой скрипт. Каждый harness описан своей секцией `[harness.<имя>]`, а `llm.harness` выбирает, каким пользоваться:

```toml
[llm]
harness = "claude"     # имя секции [harness.<имя>]; по умолчанию "ollama"
model = "haiku"        # подставляется в {model}

[harness.claude]
executable = "claude"
args = ["-p", "--model", "{model}", "--system-prompt-file", "{prompt_file}",
        "--tools", "", "--strict-mcp-config", "--disable-slash-commands", "--no-session-persistence"]
text_args = ["--output-format", "text"]
schema_args = ["--output-format", "json", "--json-schema", "{schema}"]
input = "stdin"
output = "text"
schema_output_path = "structured_output"
```

Ключи harness:

| Ключ | Что делает |
|---|---|
| `type` | `"process"` — CLI-программа (по умолчанию); `"ollama"` — HTTP-запрос к Ollama. |
| `model` | Модель по умолчанию для этого harness. Важнее `llm.model`; `model` варианта важнее её. |
| `executable` | Программа: имя в PATH, полный путь или **функция shell** (например, обёртка из `~/.zshenv`). |
| `args` | Аргументы для всех запусков. Каждый элемент — один аргумент, кавычки и экранирование не нужны. |
| `text_args` | Добавляются после `args`, если у варианта нет схемы. |
| `schema_args` | Добавляются после `args`, если у варианта есть схема (`schema = "…"`). |
| `input` | `"stdin"` — текст в stdin; `"arg"` — текст в плейсхолдер `{input}`, stdin пустой. |
| `output` | `"text"` — stdout и есть ответ; `"json"` — ответ берётся из JSON по `output_path`. |
| `output_path` | Путь к тексту в JSON-ответе, например `"result"`. |
| `schema_output_path` | Где в JSON-ответе лежит объект по схеме. Для `claude` — `"structured_output"`. |
| `[harness.<имя>.env]` | Свои переменные окружения поверх `[llm.env]`. |

Плейсхолдеры в аргументах: `{model}`, `{prompt_file}` (файл с системным промптом: `base_prompt` со словарём плюс `prompt` варианта), `{system_prompt}` (тот же промпт текстом), `{input}` (текст для LLM в обёртке `input_template`), `{schema}` и `{schema_file}` (схема текстом и файлом). Те же значения есть в переменных окружения `TAPLESS_MODEL`, `TAPLESS_PROMPT_FILE`, `TAPLESS_SCHEMA_FILE`; номер и имя варианта — в `TAPLESS_VARIANT` и `TAPLESS_VARIANT_NAME`.

Пути в JSON — ключи через точку, индексы массивов — числами (`"items.0.text"`, `"items.-1.text"` — последний). Если ответ — массив событий или JSON Lines, берётся последнее событие, в котором путь есть.

Как это работает:

- **Запуск.** Программа запускается через `llm.shell` (по умолчанию `/bin/zsh -l`) командой `"$0" "$@"`. Поэтому работают PATH, функции и алиасы из `~/.zshenv` и `~/.zprofile`, а аргументы доходят до программы без shell-разбора. Дополнительные пути задаются в `extra_path`.
- **Таймаут и отмена.** По `timeout_seconds`, по `Esc` и при новой записи TapLess останавливает программу вместе со всеми её дочерними процессами: сначала SIGTERM, через 2 с — SIGKILL.
- **Флаги claude.** `--tools ""` отключает инструменты: модель только пишет текст. `--strict-mcp-config` не подключает MCP-серверы, так быстрее.
- **Готовые пресеты** в `config.default.toml`: `claude`, `claude-bare` (быстрый старт по API-ключу), `opencode`, `llm`, `ollama`.
- **Вариант может выбрать свой harness и модель:** `harness = "opencode"`, `model = "anthropic/claude-haiku-4-5"`.

**Своя обёртка вместо `claude`.** Секции сливаются по ключам, поэтому достаточно переопределить один ключ. Например, если `claude` у вас запускается функцией `claude-proxy` из `~/.zshenv`:

```toml
[harness.claude]
executable = "claude-proxy"
```

**Быстрый старт по API-ключу.** Флаг `--bare` пропускает загрузку CLAUDE.md, хуков и плагинов, поэтому `claude` стартует заметно быстрее. Но в bare-режиме вход по подписке не используется, нужен API-ключ:

```toml
[llm]
harness = "claude-bare"

[harness.claude-bare.env]
ANTHROPIC_API_KEY = "sk-ant-..."
```

**Свой скрипт одной строкой:**

```toml
[harness.script]
executable = "/bin/sh"
args = ["-c", 'llm -m "$TAPLESS_MODEL" -s "$(cat "$TAPLESS_PROMPT_FILE")"']
```

### LLM: Ollama

Harness с `type = "ollama"` не запускает программу, а отправляет запрос в локальный сервер [Ollama](https://ollama.com) (`POST /api/chat`). Так нет затрат на старт CLI, и текст не покидает компьютер. По умолчанию все варианты идут через него.

TapLess сам готовит Ollama при запуске и после ошибки варианта:

1. Проверяет сервер (`GET /api/version`). Если он не отвечает и стоит `Ollama.app` (в `/Applications` или `~/Applications`), запускает её; если приложения нет, а есть CLI (`brew install ollama`), запускает `ollama serve` в фоне. Ждёт до 30 с. Сервер получает `OLLAMA_NUM_PARALLEL = parallel`, `OLLAMA_FLASH_ATTENTION=1` и `OLLAMA_KV_CACHE_TYPE=q8_0` (меньше памяти на контекст). Сервер, запущенный через `ollama serve`, переживает выход TapLess; его вывод — в `~/Library/Logs/TapLess/ollama.log`. Ему передаются только базовые переменные (`HOME`, `PATH`, язык) и `OLLAMA_*`, без прокси: модели он качает напрямую. Если модели доступны только через прокси, скачайте их сами (`ollama pull …`) или запускайте сервер сами. Ваши `OLLAMA_FLASH_ATTENTION` и `OLLAMA_KV_CACHE_TYPE` из окружения TapLess важнее значений TapLess. Если `ollama serve` сразу завершился (например, порт занят), в меню будет ошибка с кодом выхода.

   Если Ollama.app уже открыта, а сервер по адресу из `url` не отвечает, TapLess её не перезапускает и переменные ей не передаёт: перезапустите Ollama сами.
2. Сверяет модели вариантов со списком на сервере (`/api/tags`). Недостающие скачивает через `POST /api/pull`; качает сам сервер Ollama, прогресс — в меню.
3. Если Ollama не установлена, в меню появляется «⚠︎ Установить Ollama…» (ссылка на ollama.com). Сервер не на этом Mac TapLess не запускает: запустите его сами и нажмите «Проверить Ollama снова».

Скачать модель вручную: `ollama pull gemma4:e4b-it-q4_K_M`. Тег указывайте полностью: голый `gemma4:e4b` на Apple Silicon скачивает MLX-сборку `nvfp4` (9,5 ГБ) вместо Q4_K_M (6,6 ГБ).

Своя модель или Ollama только для одного варианта:

```toml
[harness.ollama]
model = "gemma4:e4b-it-qat"   # своя модель; остальные ключи — из пресета

[llm]
harness = "claude"            # все варианты через Claude Code…

[variants.3]
name = "Локально"
prompt = "…"
harness = "ollama"            # …а этот — через Ollama
```

Пресет `[harness.ollama]` из `config.default.toml`:

```toml
[harness.ollama]
type = "ollama"
model = "gemma4:e4b-it-q4_K_M"
url = "http://127.0.0.1:11434"
think = false          # без рассуждения: быстрее
keep_alive = "1h"      # держать модель в памяти

[harness.ollama.options]
temperature = 0.2
num_ctx = 8192
```

| Ключ | Что делает |
|---|---|
| `url` | Адрес сервера Ollama. |
| `think` | `false` — без рассуждения; `true`; или уровень `"low"` / `"medium"` / `"high"` (для `gpt-oss`). Не задан — как решит модель. |
| `keep_alive` | Сколько держать модель в памяти после запроса: `"30m"`, `"2h"`, `"-1"` — всегда. После выгрузки первый запрос ждёт загрузку модели (несколько секунд). |
| `[harness.<имя>.options]` | Параметры модели: `temperature`, `num_ctx`, `top_p` и т. д. |

Схема варианта (`schema = "…"`) уходит в Ollama параметром `format`: сервер сам ограничивает ответ схемой, затем TapLess берёт поле `result_path`.

Если вариант не удался из-за Ollama («Ollama не отвечает», «Модели … нет в Ollama»), TapLess проверяет её снова: запускает приложение и докачивает модель. Состояние — в меню, строка «Ollama: …».

**Параллельные варианты.** TapLess отправляет в Ollama не больше `parallel` запросов одновременно (по умолчанию 3, см. «Параллельность» в разделе «Варианты»). Если TapLess сам запускает сервер (Ollama.app или `ollama serve`), он передаёт ему `OLLAMA_NUM_PARALLEL` с тем же значением. Если сервер уже запущен, его `OLLAMA_NUM_PARALLEL` задаёте вы, не меньше `parallel`; без этой переменной старые версии Ollama обрабатывают один запрос за раз. Для приложения Ollama: `launchctl setenv OLLAMA_NUM_PARALLEL 3` и перезапуск Ollama; для `ollama serve` — переменная в окружении. `brew services start ollama` эту переменную не задаёт; постоянный вариант — свой LaunchAgent (`~/Library/LaunchAgents/<имя>.plist`) с `ollama serve` и ключом `EnvironmentVariables`. Каждый параллельный слот занимает память под свой контекст (`num_ctx`).

**Какую модель взять.** Замер на M4 Pro, Ollama 0.40: 10 русских текстов с IT-терминами (до ~2,5 мин речи), 3 варианта параллельно (`OLLAMA_NUM_PARALLEL=3`, `num_ctx = 8192`), качество — слепая оценка Opus по 10-балльной шкале. Память — процесс модели, без Whisper (ещё ~1,5–2 ГБ для `large-v3-turbo`, ~3 ГБ для `large-v3`).

| Модель | Панель на 2,5 мин речи | Память | Качество | Комментарий |
|---|---|---|---|---|
| `claude -p --model haiku` (для сравнения) | 12 с | — | 8,4 | Пресет `claude`. |
| `gemma4:e4b-it-q4_K_M` | 13 с | 7,8 ГБ | 6,3 | Пресет по умолчанию. Путает редкие термины и названия. |
| `hf.co/unsloth/gemma-4-E4B-it-GGUF:Q6_K` | 18 с | 9,0 ГБ | 6,7 | Чуть точнее, медленнее и тяжелее. |
| `gemma4:e4b-it-qat` | 16 с | 7,3 ГБ | 6,0 | |
| `gemma4:12b-it-qat` | 36 с | 11,9 ГБ | — | Отдельный замер: точнее `e4b-it-q4_K_M` (+0,7 балла), но в 2,5 раза медленнее и с Whisper не помещается в 12 ГБ. |
| `qwen3.5:9b-q4_K_M` | 48 с | 8,0 ГБ | 5,4 | Ollama обрабатывает варианты последовательно. |
| `gemma4:e2b-it-q8_0` | 11 с | 6,3 ГБ | 4,7 | Часто не правит термины. |

Время зависит от числа вариантов: общая скорость Ollama делится между запросами. С двумя вариантами (как по умолчанию) `e4b-it-q4_K_M` заполняет панель на 2,5 мин речи за ~9 с, с тремя — за ~14 с.

Хуже 4,5 баллов: T-lite-it-2.1 (пересказывает вместо правки, Q6_K зацикливается), `ministral-3:8b`, `qwen3.5:4b`, GigaChat3.1-10B-A1.8B (повторяет вход), `granite4.2:8b` (зацикливается).

Модели `hf.co/…` и пользовательские (`имя/модель`) скачивайте только из репозиториев, которым доверяете. Не открывайте сервер Ollama в сеть (`OLLAMA_HOST=0.0.0.0`).

### Схемы ответа

Вариант может попросить структурированный ответ по JSON Schema. Схемы лежат отдельно, в `[schemas.<имя>]`; вариант ссылается на схему по имени:

```toml
[schemas.text]
json = '''{"type": "object", "properties": {"text": {"type": "string"}}, "required": ["text"]}'''
# file = "~/schemas/text.json"   # или схема из файла (важнее json)
result_path = "text"              # какое поле вставлять; пусто — весь JSON

[variants.1]
schema = "text"               # остальные ключи варианта — из значений по умолчанию
```

С схемой TapLess добавляет к `args` не `text_args`, а `schema_args` (для `claude` это `--output-format json --json-schema {schema}`), читает ответ как JSON, берёт объект по `schema_output_path` и вставляет его поле `result_path`. Если поле не строка, вставляется JSON с отступами.

### Словарь

```toml
[dictionary]
terms = ["Claude Code", "Kubernetes", "Иван Петров"]   # как правильно пишется
notes = "Проект называется «Альфа», клиент — ООО «Бета»."

[dictionary.replace]
"клауд код" = "Claude Code"     # как распознаётся → как писать
"кубер" = "Kubernetes"
```

Словарь работает в трёх местах:

1. **Подсказка Whisper.** Термины передаются в распознавание (`initial_prompt`), поэтому редкие слова сразу распознаются правильно.
2. **Замены до ИИ.** Пары из `replace` применяются сразу после распознавания (`apply_locally`): без учёта регистра, только целые слова; пробелы и дефисы внутри фразы взаимозаменяемы. Замены выполняются за один проход: длинная фраза важнее короткой, и уже заменённый текст повторно не меняется.
3. **Промпт для LLM.** Всё попадает в системный промпт на место `{dictionary}`.

### Варианты

Вариант — таблица `[variants.<номер>]`, номер — целое число от 1 (без нулей впереди). Варианты идут по возрастанию номера; номера могут идти с пропусками. Номер задаёт порядок и имя по умолчанию («Вариант 5»), а клавиша зависит от места среди включённых вариантов.

```toml
[variants.2]                # свой промпт второго варианта; имя и остальное — по умолчанию
prompt = '''Мой промпт: …'''

[variants.3]                # новый вариант: prompt обязателен
name = "Литературный"
model = "sonnet"            # необязательно: своя модель
harness = "claude"          # необязательно: свой harness
schema = "text"             # необязательно: структурированный ответ
prompt = '''Литературная редактура: …'''

[variants.1]                # выключить вариант
enabled = false
```

По умолчанию вариантов два: «Как сказал» (вычищенная расшифровка: словарь, орфография, пунктуация, без слов-паразитов, слова автора сохраняются) и «Деловое сообщение» (спокойное деловое сообщение для мессенджера без раздражения, сарказма и скрытой агрессии).

Клавиша `1` — сырой текст «Как распознано» (`ui.show_raw`). Варианты получают клавиши 2, 3, 4… по порядку среди **включённых**, максимум 8 (клавиши 2–9). Если `ui.show_raw = false`, варианты идут с клавиши 1, максимум 9. Если выключить вариант (`enabled = false`), клавиши следующих сдвигаются. Лишние варианты не используются, TapLess предупредит об этом. Все варианты запускаются одновременно.

Ключи из файла заменяют только эти ключи варианта с тем же номером, новый номер добавляет вариант. Старый формат `[[variants]]` не поддерживается: TapLess покажет ошибку конфига.

**Параллельность.** `parallel` в `[harness.<имя>]` — сколько вариантов идёт через этот harness одновременно, остальные ждут очереди; `0` или ключа нет — без ограничения. У harness Ollama очередь общая на сервер (`url`): несколько harness на одном сервере делят его слоты. У `[harness.ollama]` по умолчанию `parallel = 3`. Если TapLess сам запускает сервер Ollama, он передаёт ему `OLLAMA_NUM_PARALLEL` с тем же значением. Уже запущенный сервер TapLess не меняет: его `OLLAMA_NUM_PARALLEL` должен быть не меньше `parallel`, иначе лишние запросы ждут на сервере. Больше параллельных запросов — больше памяти (`num_ctx` на каждый запрос), а общая скорость почти не растёт: Ollama делит её между запросами, поэтому время панели растёт примерно пропорционально числу вариантов.

### Модель распознавания

## Проверка harness вручную

Если вариант показывает ошибку, запустите программу так же, как TapLess, — через `zsh -l -c '"$0" "$@"'`:

```bash
printf 'Пиши кратко.\n' > /tmp/p.txt
echo '<transcript>ну вот короче надо проверить что клауд код работает</transcript>' \
  | zsh -l -c '"$0" "$@"' claude -p --model haiku --system-prompt-file /tmp/p.txt --tools "" --output-format text
```

Точная команда каждого запуска (с плейсхолдерами, уже подставленными) пишется в лог на уровне `debug`.

## Лог

TapLess пишет подробный лог в два места:

- **Файл** `~/Library/Logs/TapLess/TapLess.log` — меню → «Открыть лог». Эту папку видно и в Console.app → «Отчёты журналов». Когда файл больше 5 МБ, он переименовывается в `TapLess.log.1` и начинается заново.
- **Системный журнал** (Unified Logging), подсистема `io.github.aaudin90.tapless`, категории `app`, `config`, `hotkey`, `audio`, `stt`, `llm`, `paste`, `ui`. Смотреть в Console.app или в Терминале:

```bash
/usr/bin/log stream --level debug --predicate 'subsystem == "io.github.aaudin90.tapless"'
/usr/bin/log show --last 1h --info --debug --predicate 'subsystem == "io.github.aaudin90.tapless" AND category == "llm"'
```

В логе — запуск и сводка конфига, клавиши, разрешения, запись (устройство, длительность, уровень), загрузка модели, распознавание, каждый запуск harness (программа, аргументы, pid, код выхода, время, stderr), выбор и вставка. Настройки — в секции `[log]`:

```toml
[log]
level = "debug"        # debug, info, warning, error
include_text = false   # true — писать в лог сам текст диктовки и ответов
```

По умолчанию сам текст в лог не попадает, только его длина: `‹42 симв.›`.

## Частые проблемы

- **Клавиша не реагирует.** Сочетание может быть занято системой или другой программой. Посмотрите меню TapLess (там будет «⚠︎ …») и поменяйте `general.hotkey`. Сочетания `⌃Space` и `⌃⌥Space` по умолчанию переключают раскладку.
- **«Программа … не найдена».** Найдите, где лежит программа (`which claude` в Терминале), и добавьте эту папку в `llm.extra_path`. Если программа — функция или алиас shell, она должна быть определена в `~/.zshenv` или `~/.zprofile`: `~/.zshrc` при запуске не читается.
- **«Ollama: не установлена» или «сервер не отвечает».** Установите [Ollama для macOS](https://ollama.com/download/mac) или запустите `ollama serve`, затем меню → «Проверить Ollama снова». Подробности — в логе, категория `llm`.
- **Варианты пустые или просят логин (harness `claude`).** Выполните `claude` в Терминале и войдите. Для `--bare` нужен `ANTHROPIC_API_KEY`.
- **Текст копируется, но не вставляется.** Нет разрешения «Универсальный доступ», либо его сбросила пересборка (см. «Важно про подпись»).
- **Whisper выдумывает фразы на тишине.** Поднимите `stt.silence_threshold`, а повторяющиеся «галлюцинации» добавьте в `stt.drop_phrases`.
- **Приложение падает сразу при запуске после правки конфига.** Парсер TOML может упасть на синтаксически битом заголовке вроде `[[[variants]]`. Проверьте файл:
  `python3 -c "import tomllib;tomllib.load(open('$HOME/.config/tapless.toml','rb'))"`
- **Правка конфига не применилась.** Конфиг читается только при запуске: меню → «Перезапустить (применить конфиг)».
